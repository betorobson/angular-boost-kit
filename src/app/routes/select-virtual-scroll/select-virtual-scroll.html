Select Virtual Scroll

Um seletor baseado no Angular Material para listas grandes, com busca, carregamento assíncrono, seleção múltipla e opções dependentes.

Standalone Reactive Forms CDK Virtual Scroll

Instalação e importação

Importe o componente e seu tipo de configuração do pacote angular-boost-kit. No componente standalone que usa o seletor, inclua MaterialSelectVirtualScroll em imports. 

import {
  MaterialSelectVirtualScroll,
  MaterialSelectVirtualScrollConfig
} from 'angular-boost-kit';

O elemento público é <boostkit-material-select-virtual-scroll>.

Campos dependentes

populateBasedOnFormControls mantém cidades desabilitadas até que um estado seja selecionado. Ao trocar o estado, a seleção anterior é limpa e as opções são carregadas novamente.

citiesConfig: MaterialSelectVirtualScrollConfig<City> = {
  formControl: new FormControl<number | null>(null),
  compositeId: ['cityId'],
  optionItemDescription: 'cityName',

Contexto dos templates

Os templates recebem a variável contextual templateData. Para uma opção simples ela é um OptionMetaData<T>; no trigger múltiplo, é um array desse tipo. 

interface OptionMetaData<T> {
  selected: boolean;
  id: Partial<T>; // identificador montado a partir de compositeId
  data: T;         // opção original retornada por load()
}

Outputs

O componente não expõe outputs Angular próprios. Para reagir a mudanças, assine config.formControl.valueChanges; para validação e estado desabilitado, use diretamente o FormControl.

Comportamento e observações

A busca é local, aplica debounce de 200 ms e filtra apenas o campo configurado em optionItemDescription. O painel tem altura fixa de 240 px; a lista virtual usa altura de item de 48 px. load deve retornar um Observable<T[]>. Uma barra de progresso é exibida durante o carregamento. Em campos dependentes, qualquer mudança nos controles-base limpa o valor atual. O carregamento ocorre quando todos tiverem valor diferente de null. Por padrão há uma opção “None” para limpar. hideResetOption a oculta; replaceArrowByResetButton também a oculta e mostra o botão de limpar após uma seleção. compositeIdPopulateFormGroup atualiza os campos do grupo no modo simples; a combinação com seleção múltipla não é suportada. O controle deve começar com um ID que corresponda às opções carregadas para que a seleção inicial seja apresentada.
